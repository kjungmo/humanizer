## 문제

배포 스크립트가 조용히 실패하고 있었습니다. 종료 코드는 0인데 아무것도 올라가지 않았습니다.

파이프라인 안에서 난 오류를 쉘이 삼키고 있었습니다. 종료 코드만 보고 성공이라고 판단한 게 실수였습니다. 로그를 모아서 보니 마지막 명령의 결과만 남고 있었습니다. 쉘의 기본 동작이 원래 그렇습니다.

## 재현

```bash
# 진정한 혁신적인 배포 — 이 주석은 손대지 않는다
set -o pipefail
aws s3 sync ./dist s3://bucket --delete | tee deploy.log
echo "exit=$?"
```

`pipefail`이 없으면 `sync`가 실패해도 `tee`의 종료 코드가 남습니다. 파이프라인의 성패를 마지막 명령이 혼자 결정하는 셈입니다.

## 고친 것

`set -euo pipefail`을 스크립트 맨 위로 올렸습니다. `--delete` 플래그는 `s3://bucket/dist` 하위로만 걸리도록 경로를 좁혔습니다.

이제 실패하면 실패로 보고됩니다. 알림은 아직 안 붙였습니다. 다음 순서입니다.
