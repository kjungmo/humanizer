# 말투 프로필 자리

이 디렉터리에는 `python3 -m humanizer profile`이 만든 개인 말투 프로필이 들어간다.
이 파일과 `.gitignore`를 뺀 나머지는 **커밋되지 않는다.** 일부러 그렇게 두었다.

말투를 재려면 그 사람이 쓴 글을 통째로 넣어야 한다. 개인 메모장에는 거래처 이름,
동료 실명, 가족 일정, 사내 경로가 섞여 있다. 프로필은 통계만 담지만 표본 자체가
로컬에 남고, 어휘 목록을 켜면 고유명사가 그대로 들어간다. 공개 저장소에 올릴 물건이 아니다.

## 뜨는 법

```bash
python3 -m humanizer profile 표본1.md 표본2.md --name 이름
```

`voice/이름.json`(기계 판독)과 `voice/이름.md`(사람이 읽는 요약)가 생긴다.
문장이 200개 미만이면 분포를 믿을 수 없다고 경고하고 종료 코드 1을 낸다. 표본을 더 넣는다.

어휘 목록까지 남기려면 `--with-vocabulary`를 붙인다. 표본에 실명이나 거래처가 있으면 켜지 않는다.

## 쓰는 법

```bash
python3 -m humanizer detect 초안.md --voice voice/이름.json
```

개인 기준선의 1.5배까지는 그 사람 말투로 보고 S3으로 낮춘다.
줄표(J-2)·hype 어휘(D-4)·챗봇 잔재(K-1)는 낮추지 않는다. 그건 누구의 말투도 아니다.

스킬에게 시킬 때는 `voice/이름.md`를 읽히면 된다. `SKILL.md` 9절이 그걸 쓴다.

## 한 가지 주의

**말투는 하나가 아니다.** 같은 사람이라도 업무 메모, 개발 블로그, 인스타 캡션은
서로 다른 글이다. 셋을 한 표본에 섞어 평균을 내면 아무의 말투도 아닌 것이 나온다.
용도별로 따로 뜨고 이름을 나눈다. `devmemo`, `devblog`, `instagram` 이런 식으로.
